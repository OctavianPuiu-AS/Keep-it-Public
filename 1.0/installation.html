Installation

1.0

Method 1 — Drag and drop

  1. Download the .zip file.
  2. Open Blender.
  3. Drag the .zip file directly into the Blender window and drop it.
  4. A prompt will appear asking to install the extension — confirm it.
  5. Keep it is now installed and active.

Method 2 — Install from disk

  1. Download the .zip file.
  2. Open Blender and go to Edit → Preferences → Add-ons.
  3. Click the arrow (⌄) menu in the top right corner and choose Install from Disk.
  4. Navigate to the downloaded .zip file and select it.
  5. Click Install from Disk to confirm.
  6. Keep it is now installed and active.
