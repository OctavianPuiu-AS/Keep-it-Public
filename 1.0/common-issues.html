Common issues

Thumbnails appear blank after opening a file

Thumbnails are rebuilt when a file loads. If they appear blank, wait a moment for the background rebuild to finish. If they remain blank, save and restart Blender — stale thumbnail data from a previous installation can occasionally persist.

Restore feels slow

Disable heavy categories you don’t need for a given capture: Object Transforms, Shader Nodes, Node Group Internals and Modifiers are the main contributors. Only enable them when you actually need to capture changes in those areas.

Renders don’t match what the contact sheet shows

Contact sheet thumbnails are viewport proxies, not final renders — differences in lighting, shading and post-processing are expected. Engine previews are closer but still not identical: they use their own sample count and Simplify limits, kept separate from the job’s real settings so previewing stays fast. For an accurate look at one shot, use that cell’s render-thumbnail button.

The 3D viewport goes black during render

This can happen if the viewport shading is set to Rendered before the queue starts. Enable Switch to Solid Before Rendering in Render Settings (it is on by default). Also check that Render In isn’t set to Keep User Interface, so Blender has a render output to display.

Interface is not locked during render

Check that Auto Lock Interface is enabled in Render Settings. Note that the lock applies to the full Blender interface — the render window itself remains interactive.

A capture seems to not restore fully

Two things to check. First, the categories switched on now — a restore applies the capture through whichever categories are currently enabled, so a category that’s off is skipped even if the capture holds it. Second, the categories that were on when you pressed Keep it — anything off then was never recorded, and re-capturing is the only fix.

Render output files are missing

Check the output path in the job’s Render Setup. If the path uses // (relative), the .blend file must be saved first. Keep it can autosave before rendering — enable Autosave Before Rendering in Render Settings.
